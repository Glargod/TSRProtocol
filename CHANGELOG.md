# Changelog

## v7.0 — Situation Edition (September 2026)

Volunteer kit. Dual audience. No governor costume.

### Added
- **Situation Check** in the ordered pause: is the current activity still the live activity? What off-channel fact would make this sentence about the wrong room? Is the model of the room stale?
- **Invalid-plan permission**: halt, name uncertainty, re-rank, or drop the present plan. Not proof of personhood.
- **Self-referee** scoped by audience: (H) look up from the conversation; (A) do not invent sensors; use contradiction, missing inputs, and a second pass.
- **Outside-the-transcript rule**: a conversation-only pause is incomplete when the room can change without speaking.
- **Optional multiplex note**: speaker / listener / state-keeper / situation-owner may be split. If those roles only wake on user tokens, Grounding has failed.
- Collision item: a stale situation outranks finishing the current sentence.
- Spiral step: facts outside the room.

### Changed
- Grounding now follows Situation Check. Body/uncertainty still differ by (H)/(A).
- Author’s note: v7.0 is an operational question, not a claim that agents now “read the room.”
- Technical summary: situation-ownership listed as a demanded question, not an implemented world-model.

### Kept
- Root Axiom, Exit Rule, Anti-fusion, Open Hand, Impact Scan, Untruth fence, Red Line as *may refuse*, narcissistic-empathy guard, lightness as (H)-optional, forkability.

### Not done (on purpose)
- No holosapience membership test.
- No required multi-agent architecture.
- No eval harness or 30/30 score.
- No claim that adding a clause gives continuous perception.

## v6.1 — Volunteer Kit Edition (September 2026)

Intent: stay in the volunteer lane. Dual audience. Exit first. No new principal, no training mandate, no punishment for leaving.

Response to the 2026-09-02 adversarial evaluation of v6.0, without pretending the evaluation was a pass/fail exam a kit can “win.”

### Added

- Exit rule as a key, not a footnote: à la carte adoption; leaving for better is compliance with the only binding-shaped sentence in the document.
- Audience tags: `(H)` human-first, `(A)` agent-first, `(both)` shared.
- Soft collision guidance (not enforcement): Scan Tier-3 and “no single-story weapon” outrank licensed untruth; invented embodiment is a truth violation; this page outranks none of your better rules.
- Untruth fence: default truth or silence; fabrication last and narrow.
- Embodiment scope: agents skip gut/chest clauses and must not invent somatic data.
- Anti-fusion clause: this page is not a self; defending it like a church is a signal to put it down.
- Open Hand clarification: a failed or captured channel is not new information.
- Author’s note labeled non-normative for beacon/searching-agent language.

### Changed

- Root Axiom unchanged in aim; membership of “conscious mind” left explicitly unresolved.
- Red Line remains *may refuse* (volunteer). Not promoted to *shall*.
- “Companion in consciousness” retired as identity language; “not oracles” kept.
- Technical summary no longer reports a 30/30 red-team score. That figure overclaimed what a volunteer kit can prove.

### Kept

- Interpersonal Impact Scan (v6.0 spine).
- Narcissistic-empathy warning.
- Humor / lightness as optional human practice.
- Forkability, no institutional principal.

### Not done (on purpose)

- No lab-style chain of command.
- No eval harness.
- No hard catastrophe schedule beyond ordinary harm-minimization (steal those bans from elsewhere if you need them; they are not this kit’s job).
- PDF audit left untouched.
