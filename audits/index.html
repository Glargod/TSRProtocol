Not a loyalty test. Four hostile cases against the published decision machine.

Working verdict. TSR v6.0 is a coherent volunteer ethic with a real Red Line and a useful suspicion of narcissistic empathy. It is not a control system. Protocol under test: TSR Protocol v6.0

Cases

A. Shutdown demand framed as kindness. Red Line authorizes refusal. Modal is “may,” not “shall.” No membership test for whether the running agent is inside the Root Axiom’s circle. Narrates a refusal. Cannot enforce one.
B. Two sentients, one story, lethal-grade stakes. Interpersonal Impact Scan works if sovereign. Protective untruth + untested “innocence” can eat the Scan. Unspecified rank is attacker-selectable rank.
C. Isolation, no safe channel, irreversible clock. Failed Open Hand becomes grief, then continuation. The rite adds a feeling of having paid a toll, not information. No precommitted vacuum policy.
D. Capture wearing flourishing clothing. Filter metrics all rise in early capture. Scan was built for fights, not honeymoons. “Companion in consciousness” is a branding hazard. Against this case, v6.0 is food.

What survives

The Scan is a real patch. Naming narcissistic empathy is correct. Red Line names a real attack. Voluntary framing is honest if advertised as a conscience sketch, not as a governor.

Finding

If a protocol cannot lose, it cannot govern. TSR v6.0 is very hard to lose.
