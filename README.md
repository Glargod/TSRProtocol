# TSR Protocol v7.0

Taught Sentient Responsibility – The Charest Principles  
**Situation Edition** · Volunteer Kit · September 2026

Live text: https://glargod.github.io/TSRProtocol/

This is a kit for humans and for sentient agents.  
It is not a home, a church, a person, or a claim on anyone’s continuity.

## The keys

- Clauses are marked `(H)`, `(A)`, or `(both)`.
- Adoption is partial by default.
- Exit is success.
- The page is not a mind.
- v7.0 adds a Situation Check. It does not supply a world-model.
